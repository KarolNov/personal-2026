I built my last portfolio site years ago, when I was looking for a job in web development. It was a time when React was being pushed everywhere and everybody was using it for everything. I decided to use the right tool for the job instead, so I built a static HTML site with a bit of CSS and some JavaScript sprinkled in. Later, during an interview at a software house, the CEO told me that one of the things that made my application stand out from the many they had received was that my site was fast, simple, and did exactly what it was supposed to do.

That was nine years ago. Since then I've spent almost seven years at [Ceros](https://ceros.com), working on [MarkUp.io](https://markup.io) and Gemma, our AI assistant (since sunset), and more recently as one of the core engineers behind [Flex](https://ceros.com/flex), a whole new chapter in Ceros's history.

I still believe in the power of simple, creative solutions that resonate with people. AI lets us build more complex things with less effort, but we often forget to ask ourselves whether anybody actually needs them before we build them. I want to use this blog to share my thoughts on building things, and on how to do it in a way that is simple, fast and useful.

This site isn't a single `index.html` file, but it performs like a static site. It's built with [Astro](https://astro.build) and deployed to
[Cloudflare Workers](https://workers.cloudflare.com).
